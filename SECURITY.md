# Security Policy

Please report vulnerabilities privately through GitHub's
[security advisories](https://github.com/survivalizer/jellyfin-plugin-currents/security/advisories/new).
Do not open public issues for security problems.

Currents stores AIOStreams/AIOMetadata URLs (which contain credentials) in Jellyfin's plugin
configuration on the server. Treat the Jellyfin data folder as secret.
