Library

Must be reachable by both your clients and this Jellyfin server itself (its ffmpeg opens these URLs when transcoding), usually the server's LAN address, e.g. http://192.168.x.y:8096. If Jellyfin has a base URL configured, include it, e.g. http://192.168.x.y:8096/jellyfin. localhost/127.0.0.1 does not work for remote clients or when Jellyfin runs in Docker behind a different published port. Default http://127.0.0.1:8096. Changing it rewrites the .strm files on the next sync.
