AIOStreams & AIOMetadata for Jellyfin.

Catalogs (AIOMetadata)

https://your-aiometadata/stremio/<uuid>/manifest.json
SyncCatalogTypeLibraryMax itemsCollection
Unticking a catalog removes its unwatched titles after the configured number of syncs. Collection: also keep a Jellyfin collection of the catalog's titles, in catalog order. The first collection creates Jellyfin's Collections library, which runs one library scan. Unticking Collection leaves the collection in place.

Search (AIOMetadata)

Users can change this on their Currents page when self-service is allowed; the Users table below can turn it off per user.
UseCatalogTypeLibraryResults
Titles opened from search are added to the library. Titles added by search are never pruned; a catalog title opened from search stays a catalog title and can still be pruned.

Streams (AIOStreams)

https://your-aiostreams/stremio/<uuid>/<password>/manifest.json. Used for every user without their own or an assigned config.

Media

RemuxDB is a public, crowd-sourced database of probed files. Currents sends it only IMDb/TMDB ids. Its tracks are for display: playback still checks the file before using a track you picked.

Skip markers

Markers are fetched by Jellyfin's "Media Segment Scan" task and by "Fetch skip markers" after each sync that adds titles. A version only gets them when its length matches the length the markers were made for.
Default 2. A longer or shorter cut (extended, theatrical, a different release) would put the markers in the wrong place.
Applies to versions that have not been probed and that AIOStreams and RemuxDB give no length for, and to degraded mode.
Without a key TheIntroDB allows 500 lookups a day; with one, 1000.
Used for titles with a TMDB id. Leave empty to skip PublicMetaDB.

Versions

Currents is tested with Jellyfin 12.1. On another Jellyfin version it turns per-user versions off until you tick this.

Library

Must be reachable by both your clients and this Jellyfin server itself (its ffmpeg opens these URLs when transcoding), usually the server's LAN address, e.g. http://192.168.x.y:8096. If Jellyfin has a base URL configured, include it, e.g. http://192.168.x.y:8096/jellyfin. localhost/127.0.0.1 does not work for remote clients or when Jellyfin runs in Docker behind a different published port. Default http://127.0.0.1:8096. Changing it rewrites the .strm files on the next sync.
