## Defects found
1. **Fixed in 73aadfd (re-checked below).** **Series cards also appear under "Videos".** jellyfin-web's search page sends a separate query
   `GET /Items?searchTerm=…&excludeItemTypes=Movie&excludeItemTypes=Episode&excludeItemTypes=TvChannel&mediaTypes=Video&limit=100`.
   `SearchResultsFilter` appends the AIOMetadata *series* cards to it, so every series card is shown twice (Shows and
   Videos rows; seen for "Interstellar" and "Breaking Bad"). Local series are not returned there because `Series` is
   not a `Video` media type. The same query also pays the remote search wait (1.27 s). Fix direction: honour
   `mediaTypes` (no cards when it is set and excludes the card's media type) or `excludeItemTypes`/`includeItemTypes`
   consistently. Owner: Task 9 (`SearchResultsFilter`).

## Findings (not defects; need a decision or a note)
1. **Opening a series blocks for about 35 s** (single request). It meets the spec ("within a minute") and the details
   page shows everything when it appears, but a shorter refresh timeout with the queued-refresh fallback would show
   the page sooner.
2. **One AIOMetadata poster URL answered `200 text/html`** for a "Breaking Bad" search result; `PosterClient` refused it
   ("was not usable"), so that card has no poster. Upstream data, handled as designed.
3. **Card posters for search ids are served regardless of the user's search switch** (Bob with "Search add off" still
   got `200 image/jpeg` for a known search id). Jellyfin image endpoints are anonymous by design and no title is added,
   so nothing leaks beyond a public poster; noted for completeness.
4. **Search ids of titles already in the library keep working for users with search off** (Bob, search off, opening
   Interstellar's search id → 200, the existing item). Only unopened titles 404. Reasonable (the item is in a library
   he can see).
5. M2 finding 3 still applies: **Save on `/Currents/user` stores the displayed preferences and auto-select as the
   user's own** (Alice's record gained `preferences.maxSizeGb/hdr`, `autoSelect: false` and `searchAutoAdd: true`
   after toggling the switch off and on). Reset afterwards with `ClearPreferences`, `ClearAutoSelect` and
   `ClearSearchAutoAdd`.
6. M2 finding 1 (Jellyfin's `TranscodeManager` logs version tokens) is unchanged.
